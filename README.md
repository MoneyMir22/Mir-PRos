# MIR Pros — mirpros.com

Website for MIR Pros (Media Influenced Relations): AI, social media and public relations marketing.

Static site, no build step. Netlify publishes the repo root.

- `index.html` — home page
- `thanks.html` — shown after the contact form is submitted (Netlify Forms, form name `contact`)
- `_redirects` — sends www.mirpros.com to mirpros.com
